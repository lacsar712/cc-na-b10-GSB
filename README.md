# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。新登记必须单独填齐**能见度、潮位、灯器**三栏，缺任何一栏都停在登记页、不会入库；总表可按其中一栏的片段在服务端收窄。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

## 端口

| 服务 | 地址 |
|------|------|
| 页面 | http://localhost:3190 |
| 应用 | http://localhost:8190 |
| PostgreSQL | localhost:54390 |

## 账号

| 用户 | 密码 | 权限 |
|------|------|------|
| keeper | light123456 | 可登记 |
| watch | watch123456 | 只读 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格（种子行三栏为空，仍在总表）。
2. 登记一条光强低于要求的记录：若只缺潮位（能见度、灯器已填），提交后停在登记页并提示填齐三栏，记录不入库。
3. 补齐能见度、潮位、灯器后重新提交，登记成功，结论为光强不足。
4. 在总表选「灯器」栏、填新行灯器里的一个片段收窄，列表只剩这条新行；清除后恢复全部行。
5. 换 watch 登录，没有登记入口、直接提交登记会拒绝，但同样可以按栏收窄。
